Adventure Map

How the pieces fit: your photos and tracks go through a Python pipeline on your own computer, into Cloudflare storage behind a login, and out to a MapLibre map in the browser. No servers to run, no build step, and the free tiers cover one person.

The nightly run

auto_import.py, in this order. Every step only does new work, so a failed run is safe to repeat.

  1. Scan

    New geotagged photos in the photo folder; photos without GPS go to the geotag gallery.

  2. Tag

    Claude captions new photos, hides accidental shots, flags private ones.

  3. Upload photos

    Only copies not already in R2.

  4. Garmin

    New activities since the last sync.

  5. Tiles

    Rebuild changed layers; upload under content-hashed names; update tiles.json.

  6. Trips

    Detect, name tracks, name trips, upload.

  7. Deploy

    Stamp asset versions, wrangler pages deploy.

  8. Verify

    The site and a preview hostname must redirect to the login.

Storage layout

r2://photos/
  photos/<id>/thumb.webp   ~320 px, map hover + filmstrip
  photos/<id>/web.webp     ~1600 px, photo popup
  photos/<id>/pano.webp    ~4096 px, 360° viewer
  tiles/<layer>.<hash>.pmtiles   kept 3 versions deep
  data/tiles.json             current version per layer
  data/trips.json             the Trips panel
  data/trips/<trip>.json      one trip's photo points

d1://adventure-map
  pois · photo_geotags · hidden_photos
  hiked_trails · trip_names

Photo id = sha1(filename | timestamp), first 16 hex digits: stable across moves, dedupes copies.

Privacy, by design

The map is of your life; it stays yours.

One login for everything

Cloudflare Access sits in front of the page, the photos, the tiles and the API. The nightly run raises an alert if any of them answers without it.

Private photo list

private_photos.txt is filtered out of every publish step, and a purge command removes copies already uploaded.

Sensitive photos flagged

The tagging step marks photos of people undressed or children bathing as private automatically.

Credentials stay local

R2, Garmin and Claude keys live in gitignored files beside the pipeline and never reach the site.
